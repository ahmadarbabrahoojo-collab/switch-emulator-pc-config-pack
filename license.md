**Why online does not work**

Official multiplayer requires the platform's own network, which the emulator
cannot authenticate against. Local and LAN play work where the game supports it.

**If a specific title fails**

Check the renderer first (Vulkan vs OpenGL), then the CPU accuracy setting.
Most "game does not boot" reports are one of those two.

**If the controller is not detected**

1. Connect the pad **before** launching the emulator.
2. Open the input settings and pick the device by name.
3. Press a button — the mapping fields should react.
4. Save the profile so it persists.

**Motion controls**

Gyro is supported for Switch titles but needs the pad connected over
Bluetooth, not USB. Enable it per game in the input tab.
